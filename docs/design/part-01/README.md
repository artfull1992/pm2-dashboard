# Node Control · Частина 1 — Сповіщення та аудит

**На погодження.** Макети не мають статусу approved. Новий пакет доповнює, але не замінює APP-01…APP-16 і DS-01. Частини 2–5 не включені.

## Перегляд

Відкрити `gallery.html` після розпакування. Кожен PNG має посилання на локальний HTML-еталон з тим самим станом і темою. `source/index.html` відкривається без мережі; при обмеженнях file URL використати звичайний локальний static server.

У прототипі працюють переходи NTF/AUD, вкладки історії, відкриття деталей, modal-навігація, Escape, focus trap і повернення фокусу. Пошук, select, refresh, pagination, profile/settings/logout — тільки макет контрольних станів, не production-функції. Вони не звертаються до API і не змінюють дані. Стани обираються через галерею або URL-параметр `screen`.

## Вміст

- `screens/`: 74 PNG — 12 станів у двох темах на desktop/mobile; основні таблиці та деталі додатково на compact/tablet; focus, mobile-меню, reflow 200%.
- `source/`: HTML/CSS/JS, редагований прототип та Playwright renderer.
- `SPEC.md`: поведінка, дозволи, адаптивність, API fallback, відхилення DS та acceptance criteria.
- `SCREEN-CATALOG.md`, `catalog.json`: повна карта «вимога → ID → стан → тема → viewport → PNG».
- `LIGHT-TOKENS.json`: пропозиція світлої палітри; темні токени з DS-01 збережені.
- `QA.md`, `validation.json`: результати перевірки макетів та їх межі.
- `SOURCE-ANALYSIS.md`: аналіз наявних матеріалів та припущення.
- `SHA256SUMS`: контрольні суми файлів.

Шлях архіву починається з `docs/design/part-01/`. Додавати до repo після погодження; не перезаписувати чинні APP/DS. Код макетів не включати в production bundle.

## Відтворення

Node.js, Playwright та Chromium із середовища проєкту. Запустити `node source/render.cjs` з цієї папки. Для власного браузера передати абсолютний шлях через `DESIGN_CHROMIUM_PATH`. Рендеринг не потребує зовнішніх шрифтів/ресурсів. Використані під час перевірки Playwright 1.62.1 та локальний Chromium 153; інша версія/системний шрифт може змінити растеризацію.

PNG `zoom200-reflow` — приклад ефективної області 720×450 CSS px, не скриншот реального zoom. Реальний 200% і screen reader перевірити на реалізації. Поточна перевірка не доводить правильність backend-авторизації, API, повідомлень або пагінації.
