# Статус рішень

| Рішення | Статус |
|---|---|
| Загальний темний напрям B | Раніше обраний користувачем |
| APP-01…APP-16 і DS-01 | Не змінювалися цим пакетом |
| NTF-01…NTF-07 | На погодження |
| AUD-01…AUD-05 | На погодження |
| Світла палітра | Нова пропозиція |
| Drawer деталей / mobile-навігація | Пропозиція в межах частини 1 |
| Частини 2–5 | Не розпочаті |

Після рев’ю записати точні ID, тему, viewport і узгоджені правки. Не вважати всі варіанти approved через погодження одного загального напряму. Пакет з погодженими файлами формувати тільки після рішення користувача.
